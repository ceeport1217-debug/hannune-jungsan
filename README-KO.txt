한눈에 정산 웹 앱

포함 기능
- 금액을 천 원 단위로 입력 (예: 18 = 18,000원)
- 사람별 소계, 전체 합계 자동 계산
- 직접 입력과 여러 줄 일괄 입력
- 한국어 음성 입력 (브라우저 지원 여부에 따라 달라질 수 있음)
- 항목 수정 및 삭제
- 날짜별 기록 저장
- 정산 결과 복사 및 CSV 내보내기
- PWA 구성 파일 포함

중요
1. 기록은 현재 브라우저의 localStorage에 저장됩니다. 다른 기기와 자동 동기화되지 않습니다.
2. 홈 화면 설치 및 오프라인 캐시를 위해서는 HTTPS로 호스팅해야 합니다.
3. Android Chrome에서 음성 입력이 가장 잘 지원될 가능성이 높습니다. 음성 인식 시 인터넷 연결과 마이크 권한이 필요할 수 있습니다.

설치 방법(간단한 무료 배포 예: GitHub Pages)
1. 압축 파일을 풀고 파일 4개(index.html, manifest.webmanifest, sw.js, icon.svg)를 저장합니다.
2. GitHub에서 새 저장소(repository)를 만듭니다.
3. 위 파일을 저장소 최상위에 업로드합니다.
4. 저장소 Settings > Pages > Deploy from a branch > main / root를 선택해 저장합니다.
5. 생성된 https://...github.io/... 주소를 갤럭시 Chrome으로 엽니다.
6. Chrome 메뉴(⋮) > '앱 설치' 또는 '홈 화면에 추가'를 선택합니다.
7. 앱을 열고 마이크 권한을 허용한 뒤 음성 입력을 테스트합니다.
